智能配料排产软件 v3.1.83

发布日期：2026-10-10

本版本完善实时 MCP 物料切换、双草稿和分线推荐能力，并修复发布验收与 Qt Worker 生命周期问题。

更新内容

新增

  • 支持实时 MCP 物料切换与双草稿：MCP 可按稳定物料 ID 切换磷酸铁与碳酸锂，手动草稿和 MCP 草稿按物料隔离保存，过期批号覆盖在批号范围恢复后可继续使用。
  • 支持按产线异步推荐：推荐服务按各产线独立使用库存、每批配方、批数和目标计算，提供查询、取消和过期结果保护，不自动改写当前草稿。

修复

  • 保持 MCP 正式结果与手动草稿一致：MCP 排产完成后恢复手动草稿时，正式结果摘要、库存剩余量和交付事实继续保持已提交结果。
  • 修复发布验收与 Qt Worker 生命周期：忽略 Windows 临时目录的瞬时清理错误，避免已完成验收被误报失败；控制器销毁后忽略迟到 Worker 回调，避免 Qt 测试异常。

本版本增强实时 MCP 交替配料和分线推荐体验，同时收紧异步生命周期与发布验收边界。

MCP 工作台

手动配料与 MCP 配料可以在同一工作台中交替使用，物料草稿和正式结果分别按既有工作台规则维护。

  • 物料切换使用稳定 material_id，旧作用域回调自动失效。
  • 分线推荐以异步任务运行，各产线返回独立推荐结果。
  • 推荐结果需要显式应用，计算过程不覆盖手动草稿。

升级说明

本版本保留现有双厂家构建、MCP 权限、库存账本和下载发布流程。

  • Tag 发布继续执行完整测试、双厂家构建和安装包验证。
  • 更新内容由私有源码仓库的 release-notes/v3.1.83.json 生成。
  • 排产算法、库存扣减和既有客户端配置格式保持兼容。
