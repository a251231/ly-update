智能配料排产软件 v3.1.93

发布日期：2026-11-06

MES 支持 D5/BL 一起或选择性上传，完善取消回执，修复 MCP 身份隔离与 Excel 安全导出。

更新内容

新增

  • 山东渠道 MES 上传范围可选：本次上传可统一选择 D5+BL、仅 D5 或仅 BL，默认双料；预览、库存校验和提交复验使用同一范围，沿用已有明细跳过和缺失物料补录规则。

修复

  • 山东渠道 MES 取消与提交回执：取消或退出后等待当前批次结束，停止后续批次，并保留已提交、未开始及结果待核实清单。产品确认、验证料、产量与 PBCS 编辑继续使用原入口。
  • 实时 MCP 身份与权限隔离：各身份使用独立 Token，保存和删除仅影响选定身份；禁止通过共享密钥合并权限。
  • Excel 导出失败保护与文本安全：完整写入临时文件后原子发布，失败时保留旧报表；库存、供应商等外部文本不再自动解释为 Excel 公式。

兼容性/注意事项

  • 历史共享 Token 需要更换：若启用身份仍共用旧 Token，开启服务时会提示冲突。请为各身份保存独立 Token，并分别更新对应客户端配置。

本版本完善 MES 上传的选择范围和取消语义，并修复接入授权与报表交付边界。

MES 上传

  • 默认仍为 D5+BL，也可只上传 D5 或 BL；已有明细不覆盖。
  • 未选择物料不进入本次写入；上传异常后先核对 MES，再重新生成预览。

接入与交付

  • 历史共享 Token 按身份轮换后重新配置客户端。
  • 正式与普通 Excel 导出统一保留旧文件并保护文本内容。
