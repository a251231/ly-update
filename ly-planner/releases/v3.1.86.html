智能配料排产软件 v3.1.86

发布日期：2026-10-12

修复 FIFO 库龄奖励压过质量目标的问题，接通后台次优解诊断，并稳定 CI 回归检查。

更新内容

修复

  • 质量目标优先于库存偏好奖励：质量误差优先，FIFO 库龄与方差奖励仅对达标候选生效；单体与向量化评分、提前成功判定保持一致，避免偏好奖励让超标方案排在合格方案之前。
  • 真实次优解显示后台质量诊断：在后台按实际选用包数计算质量均值与供应商归因，普通警告和共享决策弹窗均可查看诊断。缺失或非有限指标保持质量未核验提示，供应商诊断详情不进入 MCP 公开响应。
  • 稳定类型检查与界面回归：补齐适应度模块类型导入，修正几何恢复测试的实际依赖位置，并隔离工作台测试设置，避免已保存窗口几何影响空态断言。

本版本修复质量优先级和次优解诊断链路，保持原有库存账本、结果确认和双厂家构建方式。

排产与诊断

  • 合格候选优先于未达标候选，FIFO 在达标候选中发挥库存周转偏好作用。
  • 质量均值与供应商归因使用实际选用包数，不再将代表多包的库存行当作一包。
  • 诊断由后台计算，界面只展示结果，不自动放宽目标或应用次优方案。

兼容性与升级说明

  • 独立 HTTP 服务默认拒绝重复 Token，实时宿主显式保留既有共享模式，不代表共享身份已实现逐身份权限隔离。
  • Tag 发布继续执行完整测试、双厂家构建和安装包验证。
  • 更新内容由 release-notes/v3.1.86.json 自动同步至更新弹窗与说明页。
