智能配料排产软件 v3.2.1

发布日期：2026-11-20

全面修复与增强山东锂源 MES 实时库存、上传防呆及桌面交互闭环，同时优化主窗口启动性能与本地/GitHub Actions 测试并行验收体系。

更新内容

修复

  • MES 实时库存去重对账、包号区间/仓库选包与写事务并发防呆：修复 PLAN_WMS_V_material 因 MES_LIMS_Records 一对多重复行导致父子权重翻倍的对账失败隐患并移除无用连接；范围批次支持全套台账括号写法，严格按 [start, end] 数字包号升序及车间对应仓库选包；在新建/补录/空主表填充事务中统一复检未耗尽占用、取消单占料与实时可用余量，并补齐 Token 过期自动重登与服务端时间校准。

新增

  • MES 登录测试连接、上传预览提效与配比状态一键回查：MES 登录弹窗新增后台只读“测试连接”；上传预览新增单批勾选/排除、同线别批量同步产品型号与验证料、PBCS 实时均衡提示以及库位/超期物料高亮警示；新增 MES 配比状态查询弹窗与待核实批次一键回查能力，并优先收敛产品型号下拉为标准全称型号。

优化

  • 主窗口冷启动提速与本地/CI 测试分层并行：消除主窗口初始化阶段的重复主题解析与过早全局事件过滤回调，单次窗口初始化由 2.31s 缩短至 0.90s；测试框架改为按需加载 Qt 并隔离进程数据与配置目录，本地 run_tests.py 与 GitHub Actions（test.yml、build.yml）全面启用 Qt 按文件多进程并行与增量验收。

本版本聚焦生产现场 MES 协同稳定性与易用性，同时提升软件启动响应速度与持续集成验收效率。

山东锂源 MES 稳定性与交互闭环

  • 实时库存查询按包去重并透传超期状态，避免 LIMS 一对多记录阻断库存刷新与每日台账更新。
  • 上传预览支持逐批勾选跳过、同线别一键填充型号/验证料、PBCS 实时均衡反馈与超期高亮，提交异常时可一键回查 MES 实际写入与审核状态。

启动响应与工程质量保障

  • 优化工作台冷启动初始化顺序，大幅减少重复样式解析与无效事件分发，打开软件更迅速。
  • 全面升级本地与 GitHub Actions 自动化测试并行隔离架构，全量门禁零弱化且执行效率提升 5 倍以上。
