Smart Material Planner Reference v3.1.95

发布日期：2026-11-07

优化通用 Excel 公式识别与 COM 读取，Reference 排产业务及实时 MCP 接入规则保持。

更新内容

修复

  • 山东版异常检测值保留原值并继续更新：检测指标为 #N/A 等明确错误值或飞书返回不可读标记时，保留台账原值、新行留空，继续更新其他有效数据。完成页列出批次、指标、来源表及行列位置；异常值不替换已有采用基线。

优化

  • 山东版业务用户自行更换来源表：来源表删除、迁移或新建替代表时，可直接更换来源并重试。在设置中选择新表、检查通过并保存后重新更新；对应关系随交接文件保存，普通换表无需修改代码。

修复

  • 动态数组公式识别及 COM 读取：排除动态数组区域中的空白和计算结果，继续保护未知真实公式；减少逐行重复读取 COM 属性，保留副本重算、保存后复读和原文件保护。

兼容性/注意事项

  • 检测缺失不代表数据合格：异常字段保留旧值仍须业务核对，新增行缺失指标不自动补值。未知复杂对象、单位和方法仍按严格规则检查；MES 上传范围及实时 MCP 单服务 Token 规则保持。
  • 厂家功能边界保持：山东版 MES/飞书台账功能继续按厂家能力隔离，不为 Reference 启用这些业务入口。

本次完善山东版“更新今日台账”的业务自助处理能力，并同步通用 Excel 改进；厂家专属入口继续按能力隔离。

山东版：来源表更换

  • 点击“更换来源并重试”，检查连接后选择新的对应工作表，再次检查并确认保存。
  • 后续交接使用新生成的台账，来源对应与采用历史一起保留。

山东版：待核数据

  • #N/A 和接口不可读检测值不作为 0，也不推测成有效数值。
  • 查看完成页列出的批次、指标与来源位置，核对人工值和缺失检测结果。
