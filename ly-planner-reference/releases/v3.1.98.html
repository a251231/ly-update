Smart Material Planner Reference v3.1.98

发布日期：2026-11-14

Reference 渠道同步升级表格读取提速、桌面核心局部重排/预检/推荐/导出修复，以及内置 AI 与实时 MCP 契约完善。

更新内容

优化

  • 台账同步依据分片优化与表格读取提速：将台账同步依据单格分段保持 8000 字符以规避 Excel/WPS COM 内存限制（0x8007000E），并优化台账来源计划与表格/批号读取链路。

修复

  • 修复局部重排、预检、推荐、导出与 MES 预览边界：修正桌面核心排产与交付链路中的选中批次局部重排、可行性供量预检、参数推荐采样、结果导出及 MES 上传预览问题。
  • 修复内置 AI 目标校验与实时 MCP 权限限流及契约：修复内置 AI 首次下发目标校验，实施实时 MCP 权限限流与 Schema 瘦身，补齐 workbench_get_run 质量摘要及 run_out 输出契约属性，并修复单传 recipe_mode=summary。

兼容性/注意事项

  • 厂家功能边界保持：山东版 MES 与飞书台账自动更新继续按厂家能力隔离，不为 Reference 启用这些业务入口。

本版本聚焦台账与表格读写性能、桌面核心排产与交付稳定性，以及内置 AI 与实时 MCP 工具契约一致性。

台账与桌面核心流程

  • 台账同步依据分片保持单格 8000 字符，降低 32 位 WPS 与 Excel COM 写入失败风险。
  • 局部重排、可行性预检、参数推荐、正式导出及 MES 上传预览边界均已对齐。

内置 AI 与实时 MCP

  • 实时 MCP 工具 Schema 进一步精简，并补齐 workbench_get_run 与 run_out 输出契约字段。
  • 仅传 recipe_mode=summary 时的返回行为已修正，保持权限与契约一致。
