Smart Material Planner Reference v3.1.97

发布日期：2026-11-13

Reference 渠道随版本同步通用更新，本次台账更新补丁仅适用于山东版。

更新内容

修复

  • 32 位 WPS 更新台账时内存不足：同步依据原先一次性写入的数据量过大，在 32 位 WPS 中会报“内存不足”（0x8007000E）。现改为分小段分批写入，同步结果与原有口径保持一致。

优化

  • 读取上一班台账大幅提速：表头合并单元格改为整段判定并二分定位，读取上一班台账的耗时由约 28 秒降至约 6 秒，不改变识别结果。
  • 台账副本更新失败时提供脱敏诊断：更新失败且无法归类时，提示信息追加异常类型、错误码与出错行号；不包含文件路径、凭据或台账内容，便于现场定位问题。

兼容性/注意事项

  • 厂家功能边界保持：山东版 MES 与飞书台账自动更新继续按厂家能力隔离，不为 Reference 启用这些业务入口。

本版本是针对 v3.1.96 的台账更新补丁，重点解决 32 位 WPS 环境下的内存不足和读取缓慢问题。

山东版：台账更新

  • 如仍遇到“台账副本更新失败”，请把提示末尾的诊断信息（异常类型、错误码、行号）反馈给维护人员。
  • 分批写入不改变同步依据、公式保护和原文件保护规则。
