Smart Material Planner Reference v3.1.80

发布日期：2026-10-09

Reference 渠道同步发布 3.1.80 更新。

更新内容

新增

  • 更新弹窗显示结构化内容：客户端按新增、优化、修复和兼容性分类展示本次版本变化，并支持滚动查看。
  • 支持查看完整版本说明：用户可以从更新弹窗打开当前版本的 GitHub Pages 说明页。

优化

  • 自动生成两个渠道的更新清单：Tag 发布读取私有仓库中的 release-notes 文件并生成 JSON 清单和 HTML 页面。

修复

  • 保持旧版更新清单兼容：缺少结构化字段的旧清单仍可使用摘要完成更新检查。

兼容性/注意事项

  • 更新链接执行 HTTPS 域名校验：客户端只打开更新渠道允许的 HTTPS 地址。
  • Reference 渠道使用独立 Windows onedir 包：请从 Reference 渠道下载对应安装包。

本版本将更新内容维护、客户端展示和公开发布同步统一到一条可审查流程。

使用说明

发现新版本后，弹窗会先展示摘要和分类更新内容。

  • 立即下载打开当前渠道的下载地址，并在需要时复制下载密码。
  • 查看完整说明打开 GitHub Pages 上的当前版本说明页。

发布说明

版本内容源文件位于私有源码仓库，公开 Pages 只保存客户端读取的投影文件。

  • 旧版 update.json 继续支持 summary 回退。
