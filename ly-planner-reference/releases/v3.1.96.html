Smart Material Planner Reference v3.1.96

发布日期：2026-11-13

Reference 渠道同步升级单进程向量化遗传算法、分仓空库阻断、桌面局部重排与跨物料配套，并保持实时 MCP 单一服务密钥规则。

更新内容

优化

  • 单进程矩阵向量化遗传算法与库龄异常年份修正：采用单进程 NumPy 矩阵向量化批量评估适应度，消除进程池创建与 IPC 开销；强化零误差质量门控，全部已设目标命中后才叠加 FIFO 与方差奖励，并修正 9999 等占位年份导致的库龄归一化失真。

修复

  • 分仓隔离空库严禁回退全库：当库存表包含合法仓库列与已知仓库值时，空分仓池将严格保持空仓状态并在预检、风险预测与求解阶段明确阻断报告缺料，防止跨仓错配。

新增

  • 桌面选中批次局部重排与跨物料配套推算：在结果面板直接开放局部重排与跨物料配套弹窗工作流，分别基于真实来源账本释放重算替换与显式分组配比取整规则生成只读草稿，并修复暗色主题对比度。

优化

  • Excel 全量指标签名汇总与原子落盘：导出器动态遍历物料全部 target_metrics 上下限生成汇总目标签名，避免不同指标约束批次误合并；移除内部库存标识列，并通过同目录临时文件原子替换落盘，外部文本保持文本格式。
  • 实时 MCP 沿用单一服务密钥并下线独立快照服务：移除独立快照 MCP 服务入口，实时服务按厂家保持唯一工作台服务密钥与统一权限（只读 11 / 默认 20 / 全开 22 项工具），并保留方案人工确认后启动排产的门禁。

新增

  • 山东版台账兼容 WPS 并支持来源启停、更换与重试：未注册 Excel 自动化组件时可调用本机 WPS 表格重算；内置及自定义飞书来源支持停用、恢复和换表，来源失效后可更换并重试，异常检测值保留原值、新行留空并列出待核位置。

兼容性/注意事项

  • 厂家功能边界保持：山东版 MES 与飞书台账自动更新继续按厂家能力隔离，不为 Reference 启用这些业务入口。

本版本聚焦排产算法精度与账本一致性、桌面高频重排配套流程，以及实时工作台 MCP 与山东版台账更新体验的统一收敛。

算法与导出

  • 默认采用单进程矩阵向量化求解，目标未全部命中时仅按质量偏差排序，库龄奖励不会覆盖超标风险。
  • 分仓开启后空仓库直接阻断排产，正式 Excel 导出按完整目标上下限拆行并原子写入目标路径。

山东版：台账与 MCP

  • “更新今日台账”优先使用 Excel，缺少 Excel 组件时自动兼容 WPS 表格重算；来源启停与换表随交接台账保存。
  • #N/A 和接口不可读检测值不作为 0，请核对完成页列出的批次、指标与来源位置。
  • 外部 AI 客户端统一通过实时工作台 HTTP MCP 服务接入，旧版独立快照 MCP 入口已从主线移除。
